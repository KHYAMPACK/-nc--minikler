## MEDIUM

### M1 — No error monitoring

No Sentry (or similar). Vercel has deployment logs. Production JS errors are invisible unless someone reports them.

**Fix:** Optional Sentry. **Do not add** without a DSN (`manual — user action required` for the account). A branded `error.tsx` (quality remediation) is the in-app fallback.

### M2 — No staging vs prod split documented

README only: push GitHub → import Vercel → attach domain. No preview-URL vs production note, no rollback steps.

**Fix:** README: Vercel Preview on PRs; prod is production branch; rollback = Vercel → Deployments → Promote previous (or revert git). Takes < 5 min.
