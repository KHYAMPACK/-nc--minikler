# Şahika Öncü Minikler Kreş

Denizli Merkezefendi butik kreş web sitesi — Next.js 15 + Tailwind CSS 4.

## Geliştirme

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Vercel

1. GitHub'a push edin
2. [vercel.com](https://vercel.com) ile projeyi import edin
3. Domain: `sahikaoncuminikler.com` (veya tercih ettiğiniz alan adı)
